## Complexity retained

Page-local requirements maps preserve requirement ordering and existing diagnostics.
Combining them changes repeated diagnostics for invalid cross-page units.
Direct grouping also changes repeated requirements and explorer units that share names with HTML units.
The review rejected those changes for this behavior-preserving pass.

The server delegates file handling to the standard library.
Compression, cache policy, and security headers each own observable behavior, covered by the server tests.
Removing them would change transfer size, cache behavior, or response headers.

Each application example remains a standalone download with its own configuration.
Sharing configuration would add a dependency outside each download directory.
The published typed IR retains its variants and serialized names because the site documents those contracts.
HTML fallback, accessibility behavior, and browser capability checks retain their current owners.
